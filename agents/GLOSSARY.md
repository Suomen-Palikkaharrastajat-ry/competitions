# Glossary & Vocabulary Canon

This document defines the canonical terminology for the **Palikkakilpailu** (LEGO MOC Competition) project to ensure clarity and reduce semantic drift, especially for LLM agents.

---

## Core Domain Concepts

- **Competition** (`kilpailu`): A single MOC building competition event with a theme, submission window, and judging period. Represented by the `competitions` PocketBase collection. Statuses: `draft → open → closed → judging → finished`.
- **Entry** (`osallistuminen`): A MOC submission by a participant for a specific competition. Contains title, description, and images. Represented by the `entries` collection. Statuses: `draft → submitted → approved / rejected`.
- **MOC** ("My Own Creation"): A LEGO build designed from scratch by the builder, not a set from official instructions. The core artifact being judged.
- **Participant** (`osallistuja`): A logged-in user who submits an entry. Any verified user account.
- **Reviewer** (`arvostelija`): A user with `is_reviewer = true` who scores and comments on submitted entries.
- **Review** (`arvostelu`): A reviewer's evaluation of an entry, consisting of one 1–5 score per review criterion and an optional comment. Represented by the `reviews` collection, whose `scores` field maps each criterion id to its score.
- **Gallery** (`galleria`): The public-facing static HTML page generated by the Haskell pipeline. Shows all approved entries, winner podium, and scores for finished competitions.
- **Winner Podium** (`voittajapodium`): The visual display of the top 3 ranked entries in a competition, shown in the gallery.
- **Authentication** (`tunnistautuminen`): Dual authentication model (ADR-0003, ADR-0006). Organisation members authenticate via Keycloak SSO (`users` collection); open participants authenticate via email OTP (One-Time Password, 6-digit code sent via Mailpit/SMTP, `local_users` collection). Both link to a shared `profiles` record.

---

## Scoring

- **Review criteria** (`arviointikriteerit`): The Likert items a review scores, each 1–5. Configured in `config.toml` under `[app]`: `criteria` lists the ids in display order, and each id's label is in `[app.strings]` as `criterion_<id>` (with translations). The current criteria:
  - `theme`: How well the MOC fits the competition theme (`teema-vastaavuus`)
  - `originality`: Originality of design (`omaperäisyys`)
  - `technique`: Build quality and technique (`rakennustekniikka`)
  - `presentation`: Photo quality and presentation (`esitys`)
- **Review total** (`arvostelun pisteet`): Sum of a review's scores, one per criterion. Maximum 5 × number of criteria (20 for the current four).
- **Total score** (`kokonaispisteet`): Sum of the scores of all published reviews, divided by the review count. Maximum 5 × number of criteria per entry.
- **Rank** (`sijoitus`): 1-based ordinal within a competition, sorted by average total score descending.

---

## Voting (ADR-0007)

- **Voting** (`äänestys`, `yleisöäänestys`): A competition's ranked vote, next to reviews. Enabled per competition (`voting_enabled`). Any signed-in user may vote.
- **Voting period** (`äänestysaika`): `voting_start_date` to `voting_end_date`; ballots are cast and changed only within it.
- **Ballot** (`ääni`, `äänestyslista`): One voter's ranking of at most five approved entries of a competition, in preference order. Represented by the `votes` collection (`ranking`: entry ids, 1st first). Readable only by the voter and reviewers.
- **Vote points** (`äänestyspisteet`): 1st = 8, 2nd = 5, 3rd = 3, 4th = 2, 5th = 1, summed over all ballots. Ties are broken by first places, then second places, and so on.
- **Required voting** (`pakollinen äänestys`): `voting_required`; an entry whose submitter cast no ballot gets no place in the vote result.
- **Vote result** (`äänestystulos`): The entries ranked by vote points. Shown live to reviewers in the admin, and in the gallery once the voting period has ended.

---

## User Roles

- **Participant** (`osallistuja`): Any authenticated user. Can submit entries to open competitions.
- **Reviewer** (`arvostelija`): User with `is_reviewer = true`. Can see all submitted entries and create/edit reviews.
- **Admin** (`ylläpitäjä`): A reviewer, in the app's admin area (`#/admin`, ADR-0004). Manages competitions, approves/rejects/resets entries. A superuser (PocketBase admin UI) also deletes competitions and manages roles.

---

## Entry Status Flow

```
draft  →  submitted  →  approved  (visible in gallery)
                    ↘  rejected   (not shown publicly)
```

- **Draft** (`luonnos`): Entry being edited; only visible to the submitter.
- **Submitted** (`lähetetty`): Entry awaiting review; visible to reviewers.
- **Approved** (`hyväksytty`): Entry passed review; visible in public gallery.
- **Rejected** (`hylätty`): Entry not accepted; visible only to submitter.

---

## Competition Status Flow

```
draft  →  open  →  closed  →  judging  →  finished
```

- **Draft** (`luonnos`): Not yet announced.
- **Open** (`avoin`): Accepting entries.
- **Closed** (`suljettu`): Submission window ended; awaiting review.
- **Judging** (`arvostelu käynnissä`): Reviewers scoring entries.
- **Finished** (`päättynyt`): Results published; gallery updated.

---

## Application Components

- **Elm App** (`elm-app/`): The interactive single-page application for authentication, entry submission, and reviewing. Runs at `http://localhost:5173` in development.
- **Haskell Gallery Pipeline** (`src/`): The `competition` executable that reads from PocketBase and generates the static gallery HTML in `dist/`.
- **PocketBase**: The SQLite-backed backend, providing REST API, auth (OTP), file storage, and admin UI. Runs at `http://127.0.0.1:8090` in development.
- **Gallery Pipeline** (`GalleryFetcher.hs`, `GalleryGen.hs`): The Haskell modules that fetch competition data and render the static HTML gallery.
- **Self-Contained HTML**: A gallery output file (`dist/galleria/index.html`) that requires no external file requests to render, except the Outfit font the site serves at `/fonts/`.

## PocketBase Collections

| Collection | Finnish | Purpose |
|-----------|---------|---------|
| `competitions` | kilpailut | Competition events |
| `entries` | osallistumiset | MOC submissions |
| `reviews` | arvostelut | Reviewer scores and comments |
| `users` | käyttäjät | Members: the shared production auth collection, Keycloak OIDC only |
| `local_users` | sähköpostikäyttäjät | Email-only participants, OTP only |
| `profiles` | profiilit | Shared domain identity of a member or an email participant |

---

## Configuration

- **`competition.toml`**: Main configuration file for the Haskell gallery pipeline. Contains title, locale, timezone, output_dir, anonymize_submitters.
- **`POCKETBASE_URL`**: Environment variable; the base URL of the PocketBase instance (e.g., `http://127.0.0.1:8090`).
- **`POCKETBASE_API_KEY`**: Environment variable; PocketBase superuser bearer token for the gallery pipeline.
- **`VITE_POCKETBASE_URL`**: Environment variable in `elm-app/.env`; injected at build time into the Elm app via Vite.

## Deprecated / Removed Terms

The following terms were used in the previous "planet" feed aggregator project and must **not** appear in new code:

- **Planet**: Use **Gallery** instead.
- **Feed** / **Feed Item**: Use **Entry** or **Competition** instead.
- **Source**: Use **Competition** or **Participant** instead.
- **`AppItem`** / **`FeedType`**: These Haskell types are deleted. Use `GalleryEntry` / `EntryStatus`.
- **`feed_items` collection**: Deleted. The active collections are `competitions`, `entries`, `reviews`.
